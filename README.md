# Satir・PAIRS Training 逐字稿研習

以 Virginia Satir PAIRS Training 工作坊逐字稿為基礎，整理成的單檔互動式研習網站。

## 內容

- `index.html`：研習網站本體（單一 HTML 檔，無外部相依套件）
  - 分章節呈現，附時間標記、技巧標籤、情境註解
  - 中英對照（原文引言 + 中文翻譯）切換
  - 每個場景可寫反思筆記（存於瀏覽器 localStorage）
- `satir/`：原始逐字稿筆記
  - `PAIRS Training-1.md`
  - `PAIRS Training-2.md`
  - `PAIRS Training-3.md`

## 線上瀏覽

啟用 GitHub Pages 後可於以下網址瀏覽：

https://tingtinghsu.github.io/Counseling_Satir_workshop/

## 本機開啟

直接用瀏覽器開啟 `index.html` 即可，無需啟動伺服器。
